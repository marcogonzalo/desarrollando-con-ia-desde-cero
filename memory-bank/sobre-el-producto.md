# Prompt para el desarrollo una Extensión de Navegador para Detección de Sitios Web Sospechosos

## Descripción del proyecto

Desarrollar una extensión de navegador que proteja a usuarios no técnicos (particulares y pequeñas empresas) de sitios web sospechosos en tiempo real, identificando riesgos como phishing, malware o estafas. La extensión ofrecerá alertas claras y consejos prácticos para evitar amenazas, con un enfoque en simplicidad, accesibilidad y educación sobre ciberseguridad.

## Características principales del MVP

1. **Detección en tiempo teal**: Analiza URLs y contenido del sitio web visitado, utilizando una base de datos de sitios maliciosos conocida y patrones de comportamiento sospechoso (por ejemplo, dominios recientes, URLs malformadas).  

2. **Alertas visuales intuitivas**: Muestra una notificación emergente (verde para seguro, rojo para peligroso, amarillo para advertencia) con un mensaje claro sobre el riesgo detectado.  

3. **Consejos prácticos**: Proporciona recomendaciones accionables según el tipo de amenaza (por ejemplo, "No ingreses datos personales, este sitio no usa HTTPS").  

4. **Interfaz minimalista**: Diseño sencillo con un botón para activar/desactivar la extensión y un panel de configuración básica (por ejemplo, nivel de sensibilidad de las alertas).  

5. **Reporte de sitios**: Permite a los usuarios reportar sitios sospechosos para mejorar la base de datos, con un formulario simple integrado en la extensión.  

6. **Compatibilidad**: Funciona en navegadores populares (Chrome, Firefox, Edge) con un enfoque inicial en Chrome.

**Objetivo**: Validar la utilidad de la extensión con usuarios no técnicos, recopilar feedback sobre la experiencia de usuario y la precisión de las detecciones, y establecer una base para futuras integraciones (por ejemplo, IA para análisis más avanzado o soporte multilenguaje).
