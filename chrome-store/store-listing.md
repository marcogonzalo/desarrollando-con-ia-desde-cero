## Título

Safe Browse Guard - Protección contra sitios web maliciosos

## Descripción Corta (132 caracteres max)

Protege tu navegación detectando sitios peligrosos, phishing y malware en tiempo real con consejos de seguridad claros.

## Descripción Detallada

### ¿Te preocupa la seguridad online? Safe Browse Guard te protege automáticamente

**🛡️ PROTECCIÓN EN TIEMPO REAL**

- Verificación automática con Google Safe Browsing API
- Detección avanzada de ataques homográficos (caracteres similares)
- Identificación de dominios sospechosos y TLDs peligrosos
- Análisis inteligente del contenido de las páginas

**🎯 DISEÑADO PARA TODOS**

- Interfaz simple y clara, perfecta para usuarios no técnicos
- Consejos prácticos específicos para cada amenaza detectada
- Página de advertencia educativa con detalles explicativos
- Modo oscuro por defecto para mejor experiencia

**🔍 DETECCIÓN AVANZADA**

- Formularios inseguros (HTTP, cross-domain)
- Scripts maliciosos y patrones peligrosos
- Campos sospechosos (datos bancarios, SSN, etc.)
- Indicadores de phishing y urgencia falsa

**⚙️ TOTALMENTE CONFIGURABLE**

- Página de opciones completa con todas las configuraciones
- Activa/desactiva funciones específicas según tus necesidades
- Importa/exporta configuraciones
- Configuración avanzada de rendimiento

**🔒 PRIVACIDAD GARANTIZADA**

- No recopilamos datos personales
- Solo verificaciones de seguridad necesarias
- Código abierto y transparente
- Caché local para mejor rendimiento

**✨ CARACTERÍSTICAS DESTACADAS**

- Notificaciones del sistema para amenazas críticas
- Indicador visual en el icono de la extensión
- Sistema de puntuación de riesgo (0-100)
- Compatible con sitios de contacto legítimos

### Perfecto para

- **Particulares** que quieren navegar seguros sin complicaciones
- **Pequeñas empresas** que necesitan protección básica
- **Familias** que quieren proteger a todos los miembros
- **Personas mayores** que pueden ser objetivos de estafas

### ¿Cómo funciona?

1. Se instala en segundos y funciona automáticamente
2. Analiza cada página que visitas sin ralentizar tu navegación
3. Te alerta inmediatamente si detecta algo sospechoso
4. Te da consejos claros sobre qué hacer en cada situación

**Navega con confianza. Instala Safe Browse Guard hoy mismo.**

## Permisos Requeridos y Justificaciones

### activeTab

**Justificación:** Necesario para analizar el contenido de la página actual y detectar amenazas en tiempo real.

### tabs

**Justificación:** Requerido para monitorear la navegación y verificar URLs antes de que se carguen completamente.

### storage

**Justificación:** Para guardar configuraciones del usuario, caché de verificaciones y preferencias de la extensión.

### notifications

**Justificación:** Mostrar alertas importantes cuando se detectan sitios peligrosos o amenazas críticas.

### webNavigation

**Justificación:** Interceptar la navegación para verificar URLs con Safe Browsing API y patrones sospechosos.

### host_permissions (<https://safebrowsing.googleapis.com/>*)

**Justificación:** Acceso a Google Safe Browsing API para verificar URLs contra la base de datos de amenazas.

### host_permissions (http://*/*, https://*/*)

**Justificación:** Necesario para analizar el contenido de todas las páginas web y detectar amenazas.

## Política de Privacidad (Resumen)

- **No recopilamos datos personales** de los usuarios
- **No vendemos información** a terceros
- **Solo verificamos URLs** con Google Safe Browsing para protección
- **Datos locales únicamente:** configuraciones y caché se almacenan localmente
- **Transparencia total:** código disponible para revisión
- **Sin tracking:** no seguimos hábitos de navegación
