# `/chrome-store` - Documentación de la Chrome Web Store

Esta carpeta contiene toda la documentación y materiales necesarios para la publicación en Chrome Web Store:

**Archivo Principal:**

- `store-listing.md`: Documentación completa con todos los textos para la Chrome Web Store
  - Título y descripción de la extensión
  - Palabras clave optimizadas para SEO
  - Descripciones de capturas de pantalla
  - Justificaciones detalladas de permisos
  - Política de privacidad resumida
  - Changelog y versioning

**Cómo usar esta carpeta:**

1. **Para crear el listing**: Copia el contenido de `store-listing.md` al formulario de Chrome Web Store
2. **Para actualizaciones**: Modifica las descripciones según nuevas características
3. **Para nuevas versiones**: Actualiza el changelog y versión
